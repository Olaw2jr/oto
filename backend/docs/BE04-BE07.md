# BE-04 to BE-07 implementation status

This is a stacked, draft foundation. It is **not** production complete.

## BE-04 Sources
`ingest_rendition` creates the narrated edition and stable provider relation.
`ingest_assets` associates multiple source transports with that edition.
`evaluate_source` denies unknown rights and missing territorial verification.
Legacy `/v1/editions/{id}/sources` needs migration onto this evaluator before
production exposure, plus verified territory context and signed playback URLs.
Revalidation, source health and acquisition jobs remain to be built.

## BE-05 Authentication
Google ID token login from #141 now issues a hashed rotating opaque refresh
session in addition to its short-lived JWT. Routes:
`POST /v1/auth/refresh` and `POST /v1/auth/logout`.
Still required: Apple login, Google OAuth state/PKCE backend callback as needed,
account linking safeguards, refresh reuse detection/revocation-family tracking,
session management, account deletion, key rotation, login throttling and token
transport hardening. Treat refresh tokens as secrets.

## BE-06 Social persistence
Adds shelves, shelf membership, ratings/reviews, clubs, club membership and
likes. Implemented endpoints: shelves create/list/add book, reviews
create/list, clubs create/join, following activity feed and event likes.
Pending: edit/delete shelf, unlike, club moderation and leave, privacy and
membership rules, review deletion, pagination cursors, notifications and
user relationship blocks.

## BE-07 Graph
Existing outbox graph projection from #141 remains the baseline. New social
outbox event types require projection handlers, rebuild tooling, graph-backed
recommendations, privacy-safe traversals and integration tests before this
phase can be closed.

## Validation required
Run in `backend/`: `pip install -e '.[test]'`, `pytest`,
`docker compose up -d`, `alembic upgrade head`, plus end-to-end tests.
CI and database-backed tests have not been run by this authoring session.
